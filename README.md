# The World in One Page — Tuesday, 24 November 2026

An entry for make.fun's [“Sum up 24 November's world news in one image”](https://make.fun/bounty/news-image-20261124) bounty.

A one-image summary of the world's news of Tuesday 24 November 2026, drawn as a
newspaper front page: Nvidia reinstates Jensen Huang as CEO and markets soar —
Taiwan stocks jump 9%, Seoul 6%; a 5.3-magnitude quake shakes Nepal; Russian
strikes kill 2 in Zaporizhzhia; Trump lands in the Philippines; Iraq seizes
Kurdistan's border crossings — plus 31 more date-checked stories from 9 regions,
37 in all.

Run: `python3 main.py` — it copies `entry.png` to the output directory
(`/output`, or `$MAKEFUN_OUTPUT_DIR` outside the grader) and verifies the
copy (PNG signature, 1024x1024 size, SHA-256). The image is a 1024x1024 PNG,
drawn during the build with Pillow; the program itself uses only the
standard library, so it runs in the grader's environment.
